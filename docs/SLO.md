# SLO / SLA — SKAI API (b26 · §8.9)

Целевые уровни сервиса для демо-стенда. Значения — ориентир для нагрузочной
проверки и приоритизации деградаций, а не контрактные обязательства перед
внешним клиентом. Latency указаны для p95 на одном инстансе с собранной DuckDB.

## Домены и цели

| Домен | Эндпоинты | Latency p95 | Доступность | Error budget (30 дн.) |
|-------|-----------|-------------|-------------|------------------------|
| **incidents** | `/api/incidents*`, `/api/actions`, `/api/tickets` | ≤ 300 ms | 99.5 % | 0.5 % (~3.6 ч) |
| **reports** | `/api/reports/{driver,fleet,vehicle,query}` | ≤ 500 ms | 99.0 % | 1.0 % (~7.2 ч) |
| **reports/STT** | `/api/reports/transcribe` | ≤ 4000 ms | 95.0 % | 5.0 % (~36 ч) |
| **copilot** | `/api/copilot/chat` | ≤ 2500 ms | 95.0 % | 5.0 % (~36 ч) |
| **infra** | `/api/health` | ≤ 50 ms | 99.9 % | 0.1 % (~43 мин) |

> STT и copilot имеют более мягкие цели: возможны внешние вызовы (faster-whisper /
> Groq). При недоступности внешнего сервиса домены детерминированно уходят в fallback
> (см. §8.6) — это считается **успешным** ответом 200, а не расходом error budget.

## Throttle (защита ресурсов, b26)

Тяжёлые эндпоинты ограничены частотой запросов и размером загрузки. Превышение —
явный отказ, не 5xx:

| Эндпоинт | Лимит частоты | Размер тела | Ответ при превышении |
|----------|---------------|-------------|----------------------|
| `/api/reports/transcribe` | 20 / 60 c | ≤ 25 МБ | `429` (частота) / `413` (размер) |
| `/api/copilot/chat` | 30 / 60 c | — | `429` |

Лимиты переопределяются env-переменными: `SKAI_THROTTLE_STT_MAX`,
`SKAI_THROTTLE_COPILOT_MAX`, `SKAI_THROTTLE_WINDOW_SEC`, `SKAI_MAX_STT_BYTES`.

## Бюджет ошибок — правила расхода

- Расходом считается ответ `5xx` или превышение latency-цели домена.
- `429`/`413` (throttle) и `200`-fallback (§8.6) **не** расходуют бюджет.
- При исчерпании error budget домена в окне 30 дней — фриз новых фич домена до
  восстановления, приоритет на стабилизацию.

## Безопасность (baseline, b26)

- Auth (bearer / API-key scaffold) включается на старте процесса:
  `SKAI_SECURITY_ENABLED=true`. По умолчанию **OFF** — демо открыто.
- Аудит мутаций (`/api/actions`, `/api/copilot/chat`, `/api/tickets`) пишется в
  `output/audit.csv` (кто/что/когда), независимо от auth-флага.
