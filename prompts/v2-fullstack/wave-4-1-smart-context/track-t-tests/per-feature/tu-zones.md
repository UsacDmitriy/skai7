## Цель

Покрыть детерминизм кластеризации и форму зон риска без сети.

## Состав — `api/tests/unit/test_zones.py`

- `compute_zones()` детерминирован: фиксированные `eps/min_samples` → стабильные `zone_id`/центроиды.
- Есть зоны `kind=incident` и `kind=reb`; `avg_risk ∈ [0,100]`, `radius_m > 0`, `peak_hour ∈ 0..23`.
- Фильтры: только `kind=reb` отдаёт РЭБ-зоны; `hour` фильтрует по `peak_hour`.
- Нет подходящих точек → `[]` (не ошибка).

## Check

- `pytest api/tests/unit/test_zones.py -q` зелёный без сети.
- Детерминизм кластеров, оба `kind`, фильтры и пустой кейс проверены.
