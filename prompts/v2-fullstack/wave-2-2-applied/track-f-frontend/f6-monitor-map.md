# f6 · Живой мониторинг — карта (`/monitor`)

> Трек **Frontend**. Против `00-CONTRACT.md` §3 + §6 (AC «Монитор») + §7.6/§7.8 (карта/роли).
> **Модель:** 🔴 Opus — высокие ставки: интеграция / синк / алгоритм / анти-регресс / killer-feature / барьер.
> **Владеет:** `web/src/pages/Monitor.tsx` (**полный, заменяет scaffold из f4**). Использует map-примитивы
> d4 (`MapView`, `MarkerLayer`, `RoleToggle`), UI-примитивы d2 (`@/components`) и API-клиент f2.
> Идея #4/#10 «Живой мониторинг». Иконки — `lucide-react`.

## Цель

Боевой экран дежурного 24/7: тёмная Leaflet-карта парка, один маркер на ТС (дедуп), цвет по severity,
лента активных алярмов справа, ролевые слои. **Этот файл заменяет scaffold-версию `Monitor.tsx` из f4** —
после full-scope `Monitor.tsx` принадлежит f6 (см. §7.7). Маршрут `/monitor` (f1).

## Экран

Данные: `client.listIncidents()` → `IncidentSummary[]`. Поля по §3.1, схему не дублировать.

- **Дедупликация ТС (§6/§7.6, критично):** из плоского списка алярмов собрать `MapUnit[]` (контракт d4):
  один объект на `unit_id`, выбирая наихудший/последний алярм как `last_alarm`. `MarkerLayer` дополнительно
  защищён от дублей, но входной массив уже дедуплицирован здесь. Маркер ставится только при наличии
  `lat`/`lon` (nullable в §3.1).
- **Карта** — `MapView` (тёмная тема, тайлы dark, кластеризация r=40px) + `MarkerLayer`
  (цвет по severity — маппинг d1; кольцо online/offline). `onSelect(unit_id)` подсвечивает ТС и
  скроллит к нему в ленте; попап маркера ведёт на `/incidents/:id`.
- **Лента активных алярмов справа** — список `Card(variant=incident)` с severity-border, сортировка по
  `ts`/`risk_score`. Клик по карточке → `/incidents/:id`.
- **Ролевой режим** — `RoleToggle` (d4). **Логист — без DMS-алармов** (фильтровать `source` так, чтобы
  DMS/COMBINED-по-DMS не попадали; Логист видит телематику/ADAS); Диспетчер/Безопасник — все слои.
  Роль фильтрует и маркеры, и ленту.
- **Фильтры**: «Все» / «Критичные» (`severity==='critical'`) / «Без видео» (`video_available===false`).
- Состояния loading/error/empty (карта рендерится даже при пустой ленте).

## Зависимости и параллельность

- Зависит от: **d4** (`MapView`, `MarkerLayer`, `RoleToggle` + типы `MapUnit`/`Role`), **f2**
  (`listIncidents`), **d2** (`Card`, `SeverityBadge`). Маршрут — f1.
- Параллелится с f5/f7/f8. Конфликт владения только с f4-scaffold — он замещается (зафиксировать при
  запуске Волны 2 (расширение), §7.7).
- Ролевое состояние пересекается с f13: здесь — самодостаточная фильтрация по роли внутри `Monitor`.

## Check

- `/monitor` открывается на живом API и на фикстурах (`VITE_USE_FIXTURES=true`), карта рендерит тёмные тайлы.
- На карте ровно **один маркер на `unit_id`** (дедуп), даже если у ТС несколько алярмов в списке.
- Цвет маркера соответствует severity-маппингу d1; кольцо online/offline видно.
- В роли «Логист» DMS-алярмы отсутствуют и на карте, и в ленте; Диспетчер/Безопасник видят всё.
- Фильтры «Все/Критичные/Без видео» корректно сужают маркеры и ленту.
- Клик по маркеру/карточке открывает `/incidents/:id`; `onSelect` синхронизирует подсветку.
- Файл полностью заменяет scaffold `Monitor.tsx` из f4 (нет дублирующего экспорта/маршрута).

## Состояния и edge-cases

- **empty**: пустой список → карта всё равно рендерится (тёмные тайлы), лента показывает empty-state; счётчик активных = 0.
- **error**: ошибка `listIncidents` → состояние ошибки над лентой + «Повторить»; карта не падает.
- **loading**: скелет ленты + спиннер слоя маркеров; карта монтируется сразу.
- **Дедуп/координаты**: ровно 1 маркер на `unit_id` (наихудший/последний `last_alarm`); алярмы с `lat===null || lon===null` на карту не ставятся, но **остаются в ленте** (бейдж «без координат»), не теряются.
- **Тёмная тема**: тёмные тайлы + контрастные маркеры; цвет по severity (маппинг d1) различим на тёмном фоне; кольцо online/offline видно.
- **Роли**: «Логист» скрывает DMS (`source ∈ {DMS, COMBINED}` по DMS-части) и на карте, и в ленте синхронно; смена роли не оставляет «осиротевших» маркеров.
- **Локали**: время алярма в ленте — таймзона парка из UTC-`ts`; числа `tabular-nums`.
- **a11y**: маркеры доступны с клавиатуры (focus/Enter → попап→карточка), `aria-label` маркера (ТС + severity); `RoleToggle`/фильтры — `aria-pressed`; подсветка `onSelect` дублируется не только цветом.
