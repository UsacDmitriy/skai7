# f11 · РЭБ-восстановление трека (идея #8)

> Трек **Frontend**. Против `00-CONTRACT.md` §7.4 (`GET /api/reb/{id}`), §7.5 (`RebRecovery`),
> §7.8 (AC «РЭБ»). **Владеет:** `web/src/pages/RebRecovery.tsx`. Использует примитивы карты d4
> (`@/components/map`: `MapView`, `MarkerLayer`), таймлайн d5 (`@/components/ui/Timeline`), UI-примитивы
> d2 (`Button`, `VideoPlayer`) и API-клиент f2.

## Цель

При глушении/потере GPS (РЭБ) GPS-трек рвётся, но видео продолжает писаться. Идея #8: показать, что
происходило в моменты потери сигнала — наложить на карту имеющийся GPS-трек с разрывами и подтянуть
соседние видеокадры момента потери. Источник на бэке — `navigation_problem_tracks` (`period_type=3`).

## RebRecovery.tsx

Маршрут `/reb/:id`. Данные — `client.getReb(id)` →
`RebRecovery { vehicle_plate, gps_track: {lat,lon,ts}[], gap_periods: {start,end,duration_sec}[],
video_frames: {ts, channel, url}[] }`.

Раскладка:
- **Шапка**: `vehicle_plate`, суммарная длительность разрывов (Σ `gap_periods[].duration_sec`),
  число разрывов.
- **Карта** (`MapView` d4) с двумя визуальными слоями:
  - **GPS-трек с разрывами**: рисуем `gps_track` сплошной линией там, где сигнал был; интервалы из
    `gap_periods` — пунктир/полупрозрачная линия между точками до/после разрыва (gap-сегмент).
  - **Видеокадры момента потери**: `MarkerLayer` маркерами на позициях, ближайших к началу разрыва —
    клик открывает соседний видеокадр (`video_frames[]`).
- **Таймлайн GPS работал/нет** (`Timeline` d5): полоса по времени рейса — зелёные сегменты «GPS есть»,
  серые/красные сегменты `gap_periods` «сигнал потерян». Клик по gap-сегменту → выбрать разрыв.
- **Видеокадры разрыва** (`VideoPlayer` / кадры): для выбранного `gap_period` показать соседние
  `video_frames` (ts внутри/рядом с разрывом), подпись «Видео есть, GPS нет · {duration_sec}с».
- Синхронизация: выбор разрыва на таймлайне ↔ подсветка gap-сегмента на карте ↔ видеокадры.
- Состояния loading / error / 404; пустое состояние «Разрывов GPS не найдено».

## Зависимости и параллелизм

- **Опирается на:** d4 (`MapView`/`MarkerLayer` — нужна поддержка разрыва линии/пунктира; согласовать с d4),
  d5 (`Timeline` с сегментами-периодами), d2 (`VideoPlayer`/`Button`), f2-клиент.
- **f2/x2:** f2-клиент дополняется методом `getReb(id) → RebRecovery` (тип `RebRecovery` в `types.ts`
  пополю по §7.5). Маршрут `/reb/:id` добавляется в `App.tsx` (зона f1/x2).
- **Бэк:** `GET /api/reb/{id}` (b12, `v_reb`). До готовности — фикстуры f3 (`VITE_USE_FIXTURES=true`).
- **Можно параллелить** с f9/f10/f12/f13: отдельная страница, пересечения только в `App.tsx` и
  `client.ts`/`types.ts`. Делит d4 с f6/f10 (компонент, не файл).

## Состояния и edge-cases

- **loading**: скелетон карты/таймлайна (без layout-shift), aria-busy на области карты.
- **error** (сеть/5xx): блок ошибки + кнопка «Повторить» (повторный `getReb(id)`), карта не рендерится «битой».
- **404 / нет данных по id**: «Рейс не найден» (не пустой экран, не падение).
- **`gap_periods=[]`** (трек непрерывный): empty-state «Разрывов GPS не найдено», карта показывает сплошной трек.
- **`gps_track=[]`** (нет точек вовсе): карта на дефолтном центре + «Нет GPS-данных», без падения на пустом массиве.
- **`video_frames=[]`** для выбранного разрыва: вместо плеера подпись «Видео за момент потери отсутствует».

## Check

- `/reb/:id` рисует GPS-трек, где разрывы (`gap_periods`) визуально отличаются от непрерывных участков.
- Таймлайн показывает чередование «GPS есть / GPS потерян» по времени рейса.
- Клик по разрыву на таймлайне подсвечивает gap-сегмент на карте и показывает соседние видеокадры.
- Видеокадры тянутся по `video_frames[].channel/url`; подпись «Видео есть, GPS нет».
- Состояния loading / error («Повторить») / 404 / пустые `gap_periods`/`gps_track`/`video_frames` — без падения.
- a11y: разрыв на таймлайне фокусируем и активируется с клавиатуры (Enter/Space, `role`+`tabindex`/кнопка);
  выбранный разрыв помечен `aria-selected`/`aria-current`; видеокадры с `alt`/подписью канала; даты в локали/таймзоне.
- Работает на живом API и на фикстурах (`VITE_USE_FIXTURES=true`).
- `npm run typecheck` проходит; `RebRecovery` совпадает с §7.5 пополю.
