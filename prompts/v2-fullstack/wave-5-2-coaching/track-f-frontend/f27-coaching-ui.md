# f27 · Секция «Обучение водителя» в отчёте (фича #24, §12.4)

> Трек **Frontend**. Против `00-CONTRACT.md` §12.3/§12.4. **Владеет:** **аддитивной** правкой
> `web/src/pages/Report.tsx` (driver-ветка) + `web/src/api/types.ts`, `web/src/api/client.ts`,
> `web/src/api/fixtures.ts`. **Модель:** 🔵 Sonnet — секция отчёта против контракта; гейт = typecheck + vitest.
> **Волна 5.2**, окно 2 (web). Зависит от: b32 (эндпоинты §12.2).

## Цель

Руководитель в отчёте водителя видит цикл обучения: какие курсы назначены по инцидентам, сдан ли
тест (18/20), есть ли повторные нарушения — с честным бейджем «синтетические данные (демо)».

## Состав

1. **Типы** (`types.ts`, аддитивно): `CoachingAssignment`, `CoachingKpi`, `CoachingSummary`,
   `CoachingCard` — **дословно §12.3** (включая литерал `synthetic: true`).
2. **Клиент** (`client.ts`, за свитчем `USE_FIXTURES`): `getCoaching(plate)` →
   `GET /api/coaching/{plate}` (сводка `getCoachingSummary()` — опционально, если ляжет в экран).
3. **Фикстуры** (`fixtures.ts`): `CoachingCard` с тремя назначениями — по одному в статусах
   `passed`/`failed`/`incomplete`, у одного `repeat_within_30d: true`; KPI согласованы со списком.
4. **`Report.tsx`** (строго аддитивно, driver-ветка): секция «Обучение водителя» ПОСЛЕ существующих
   KPI-блоков (ориентир — блок дисциплинарного предупреждения):
   - **бейдж «синтетические данные (демо)»** — обязателен, warning-тон, рядом с заголовком (§12.0);
   - KPI-чипы: «Завершение {completion_rate}%», «Сдача теста {pass_rate}%»,
     «Повторные нарушения {repeat_violation_rate}%» (повторные — danger-тон при >0);
   - таблица назначений: курс, назначено/дедлайн, балл `{test_score}/20`, статус-чип
     (`passed` ✓ / `failed` ✗ / `incomplete` ⏳), флажок «повтор за 30 дней»;
   - клик по строке → `/incidents/{incident_id}` (первопричина);
   - состояния: loading/error — секцию тихо скрыть (отчёт не ломать); пустые назначения —
     «обучение не назначалось» (не скрывать секцию: пустота информативна).
5. **A11y:** статус не только цветом (иконка/текст); таблица с заголовками.

## Check

- В отчёте водителя с назначениями секция видна: бейдж синтетики, 3 KPI-чипа, таблица, переходы
  на карточки инцидентов работают.
- Водитель без назначений → «обучение не назначалось» + нулевые KPI; ошибка API → секция скрыта,
  остальной отчёт работает.
- Паритет: живой API и `VITE_USE_FIXTURES=true` (все три статуса + повтор-флажок).
- `npm run typecheck` зелёный; vitest: рендер секции на фикстуре (3 статуса), бейдж синтетики
  присутствует, пустой кейс; существующие тесты `Report.*` зелёные (правка аддитивна).
