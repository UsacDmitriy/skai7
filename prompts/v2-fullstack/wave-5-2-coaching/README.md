# Волна 5.2 · Coaching Loop — цикл обучения водителя (демо на синтетике)

Вторая под-волна Волны 5 (после барьера x10). Замкнутый цикл Оздоева: инцидент → назначение курса →
тест (18/20) → KPI повторных нарушений. Кодим против `00-CONTRACT.md` **§12**. Backend (датасет →
сервис) → web ∥ tests.

> **Клиентское обоснование (дословно Оздоев, Газпромнефть):** «убрать формальную работу с
> руководителей» — авто-назначение обучения по инциденту, тест с порогом 18/20, эскалация при
> повторе за 30 дней. **Паттерн лидеров:** Samsara coaching effectiveness, Lytx coaching workflow.
> Самая монетизируемая фича бэклога (`WAVE-5-BACKLOG.md` W5-2).
>
> ⚠️ **Честность данных:** датасета обучения не существует → генерим **детерминированную синтетику**
> из реальных алармов (паттерн `driver_reference`, §12.0). `repeat_within_30d` — реальный расчёт.
> UI обязан показывать бейдж «синтетические данные (демо)». HR-интеграцию НЕ обещаем.
