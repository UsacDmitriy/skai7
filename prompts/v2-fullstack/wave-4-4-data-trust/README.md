# Волна 4.4 · Data Trust — консистентность данных (валидатор + кросс-сверка скоростей)

Под-волна после **барьера x8** (финал Волны 4, `main` уже продвинут). Закрывает главный блокер доверия
из клиентских интервью: **расхождения данных между телематикой и видеоаналитикой**. Кодим против
`00-CONTRACT.md` **§10** (аддендум Data Trust). Backend → web ∥ tests.

> **Почему отдельная под-волна.** Фичи №21/№22 (`FEATURES.md`) — детерминированный SQL-слой без AI,
> со своим гейтом x9. Встраивание в 4.3 дестабилизировало бы подготовленный финал x8.
>
> **Клиентское обоснование:** Фомин (PepsiCo) — «видео показывает одну скорость, CAN другую», 39 ДТП →
> видео подтвердило 5 (→ `evidence_rate`); Маслов (Балтика) — дубли терминалов на одном ТС
> (→ `terminal_duplication`). Конкурентный паттерн — Lytx event-review/data-trust (см. `../COMPETITORS.md`).
