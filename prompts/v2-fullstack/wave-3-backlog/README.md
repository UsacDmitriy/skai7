# Волна 3 · бэклог некритичных доработок

> **Не входит в P0/P1/P2-скоуп.** Накопленные неблокирующие правки и улучшения продукта,
> выявленные аудитами после Волн 1/2. Не блокируют релиз; выполняются **по мере готовности
> трека-владельца**, на его ветке `feat/*`, и подтягиваются обычным `git merge` на барьере.
> Источник истины прежний — `00-CONTRACT.md`.

## Когда запускать

Любой пункт W3 можно брать, как только освободился его трек-владелец (см. колонку «Трек»).
Порядок между пунктами не важен — зависимостей между ними нет. Барьер для Волны 3 отдельный
не нужен: правки приезжают в `integration`/`main` обычным мержем ветки трека.

## Куда складывать новые пункты

Каждый новый некритичный дефект/улучшение из аудита → **отдельный файл** `wN-*.md` здесь
(один промпт = один файл, см. правило README трека) + строка в таблице
«Волна 3 · бэклог доработок» в `../EXECUTION.md`. Так бэклог остаётся executable, а не текстом.
