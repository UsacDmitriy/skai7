# f17 · Copilot UI — чат-ассистент (идея #13)

> Трек **Frontend**. Против `00-CONTRACT.md` §8.3/§8.4 + §7.8 (состояния). **Владеет:**
> `web/src/pages/Copilot.tsx` (или панель-drawer), `web/src/api/copilot.ts`; UI d2, f2-клиент.
> **Модель:** 🔴 Opus — сложный интерактив (стриминг/состояния/a11y/двуязычность).
> **Волна 4.2**, окно 2 (web). Зависит от: `POST /api/copilot/chat` (b21), маршрут/панель в `App.tsx`.

## Цель

Разговорный копилот по данным SKAI: поле ввода (RU/EN) → ответ ассистента + связанные данные
(карточки/таблицы/ссылки на экраны). Доступен как панель поверх любого экрана.

## Состав

- `copilot.ts` — тонкий слой над `POST /api/copilot/chat` (`CopilotMessage`); уважает `VITE_USE_FIXTURES`
  (детерминированные ответы-моки на типовые запросы).
- `Copilot.tsx` — лента сообщений (user/assistant), индикатор печати, рендер `data` ответа
  (если `tool_calls` вернул инциденты/прогноз/зоны — показать компактно + ссылка на экран).
- **Состояния:** idle/loading/ready/error (retry); пустой ввод заблокирован; язык ответа = языку запроса.
- **a11y:** роль `log`/`dialog`, фокус-менеджмент, клавиатура (Enter — отправить), aria-live для новых сообщений.

## Check

- Панель открывается поверх экрана; запрос «кто в группе риска?» → ответ + данные; язык совпадает (RU/EN).
- На фикстурах (`VITE_USE_FIXTURES`) работает без сети; ошибка сети → плашка + «Повторить».
- a11y: клавиатура/скринридер; `npm run typecheck` зелёный.
- **Метрики (b25):** на вызов инструмента эмитит `copilot_tool_called`/`copilot_tool_success`
  (эмиттер b25; без сети — no-op). Питает `copilot_tool_success`.
