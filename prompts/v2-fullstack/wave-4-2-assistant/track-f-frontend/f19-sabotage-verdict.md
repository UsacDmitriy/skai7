# f19 · Smart sabotage verdict UI (идея #16)

> **Волна 4.2**, окно 2 (web). Зависит от: b23 (`verdict_confidence`/`verdict_reason` в `SabotageEvent`).

## Цель

Показать «умный вердикт» саботажа: индикатор уверенности + объяснение (что усилило/ослабило), чтобы
оператор видел не просто «тёмный DMS», а обоснованную оценку с учётом внешних условий.

## Состав

- В `SabotageWidget.tsx` (аддитивно): gauge/бейдж `verdict_confidence` (0..1) + текст `verdict_reason`
  («день/ясно снаружи — камера должна была видеть» / «ночь/туман — объяснимо»).
- Состояния: нет полей вердикта (старые данные) → прежний вид без вердикта (обратная совместимость).

## Check

- Виджет показывает уверенность + причину; высокий confidence при «день/ясно», ниже при «ночь/туман».
- Старые `SabotageEvent` без полей вердикта → прежний вид (без падения); `npm run typecheck` зелёный.
