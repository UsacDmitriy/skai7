## Цель

Руководитель видит рейтинг водителей одним списком (видео+телематика в одном числе) и «зелёную
зону» Оздоева; в отчёте водителя — позитивная сторона вождения, не только нарушения.

## Состав

1. **Типы** (`types.ts`, аддитивно): `PositiveScore`, `DriverScore` — **дословно §13.1/§13.2**.
2. **Клиент** (`client.ts`, за свитчем `USE_FIXTURES`): `getLeaderboard()` → `GET /api/driver-score`;
   `getPositiveScore(plate)` → `GET /api/positive-score/{plate}`.
3. **Фикстуры** (`fixtures.ts`): лидерборд ≥5 строк (разные `unified_score`, ≥1 `green_zone: true`,
   ≥1 ТС без алармов с `avg_risk_score: 0`); `PositiveScore` — обычный и «чистый» (все ratio 1.0).
4. **`Leaderboard.tsx`** (`/leaderboard`):
   - заголовок + **дисклеймер «за период {period_days} дн.»** (§13.0 — обязателен);
   - таблица: место (1..N), водитель, ТС, `unified_score` (крупно), мини-разбивка
     (risk/positive компоненты), бейдж 🟢 «зелёная зона»;
   - клик по строке → отчёт водителя (`/report` с предвыбранным ТС — использовать существующий
     механизм перехода в отчёт, как делают другие экраны);
   - состояния loading/empty/error.
5. **`App.tsx`** (аддитивно): lazy-роут `/leaderboard`; NAV-пункт «Рейтинг водителей» в группе
   «Дашборды и отчёты» (без бейджа — живой экран).
6. **`Report.tsx`** (аддитивно, driver-ветка): блок «Позитивное вождение» **после** секции
   обучения (f27): `positive_score` крупно, бейдж green_zone, три составляющие
   (соблюдение лимитов / чистые дни / без резких манёвров) с долями, дисклеймер периода;
   ошибка API → блок тихо скрыт (отчёт не ломать).
7. **A11y:** место и green-zone не только цветом; таблица с заголовками; фокус-навигация по строкам.

## Check

- `/leaderboard` в NAV и рендерит таблицу: сортировка визуально совпадает с API (1-е место —
  максимальный `unified_score`); дисклеймер периода виден; green-zone бейдж у нужных строк.
- В отчёте водителя блок позитива ПОСЛЕ секции обучения; составляющие согласованы с
  `/api/positive-score/{plate}`; при ошибке API блок скрыт, отчёт работает.
- Клик по строке лидерборда открывает отчёт нужного водителя.
- Паритет: живой API и `VITE_USE_FIXTURES=true` (включая «чистый» кейс и green-zone).
- `npm run typecheck` зелёный; vitest: рендер лидерборда (порядок строк по фикстуре), дисклеймер
  присутствует, блок позитива в отчёте, пустой/error кейсы; существующие тесты `Report.*`/`App.test.tsx`
  зелёные (NAV-пункт добавлен — обновить snapshot/ассерты при необходимости).
