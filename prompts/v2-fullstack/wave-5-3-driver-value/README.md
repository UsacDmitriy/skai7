# Волна 5.3 · Driver Value — позитивный скоринг + единый рейтинг водителей

Третья под-волна Волны 5 (после барьера x11, финал Волны 5). Переворачивает оптику с «ловить
нарушения» на «признавать хорошее вождение»: green-zone Оздоева + единый рейтинг, блендящий риск
и позитив. Кодим против `00-CONTRACT.md` **§13**. Backend (b33→b34) → web ∥ tests.

> **Клиентское обоснование:** Оздоев трекает KPI «зелёная зона»; все три клиента ведут рейтинги
> водителей. **Паттерн лидера:** Netradyne DriverStar/GreenZone — признание хорошего вождения
> снижает текучку и повторные нарушения (`../COMPETITORS.md`).
>
> ⚠️ **Скоуп-границы:** полная геймификация (баллы/команды/призы/чат-бот Оздоева) — НЕ здесь,
> остаток W5-4 в `WAVE-5-BACKLOG.md` (нужен мобильный канал водителя). Здесь — скоринг + лидерборд.
> **Дисклеймер периода обязателен** (§13.0): датасет покрывает мало дней.
