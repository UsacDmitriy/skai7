(`git add -A && git commit`), затем `git fetch && git merge integration` — иначе merge упрётся в грязный
worktree. Каждый тест-промпт заканчивается секцией `## Коммит`. Баги **эскалируются** треку-владельцу,
в тестах не правятся. Схема — [`../EXECUTION.md`](../EXECUTION.md).
