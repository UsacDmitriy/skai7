# tu-sabotage · Unit-тесты детекции саботажа (фича #9, модуль b11)

## Цель

Покрыть детерминированное правило `v_sabotage`/классификатор саботажа (`b11`): тёмный DMS-канал
(или `CAMERA_TAMPER`) при `speed_kmh > 0` — событие; иначе нет. Граничные кейсы и пустой список.

## Состав — `api/tests/unit/test_sabotage.py`

- Тёмный DMS + `speed_kmh > 0` → событие саботажа; поля `SabotageEvent` (§7.5) заполнены.
- Граница `speed_kmh = 0` при тёмном канале → **не** событие.
- Камера `ok` при движении → **не** событие.
- `CAMERA_TAMPER` при движении → событие.
- Нет подходящих строк → пустой список (не ошибка), детерминированно.

## Check

- `pytest api/tests/unit/test_sabotage.py -q` зелёный.
- Границы (`speed=0`, камера ok) дают «не событие»; happy-кейс даёт валидный `SabotageEvent`.
- Тесты не требуют сети/uvicorn; углубление — в `w3-3`.
