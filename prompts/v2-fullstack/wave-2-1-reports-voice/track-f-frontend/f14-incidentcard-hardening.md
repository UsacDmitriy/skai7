## Цель

Довести «Карточку инцидента» (идея #1) до Definition of Done на живом API и фикстурах
(`VITE_USE_FIXTURES=true`): состояния loading/empty/error, синк видео↔график, a11y, локали, роли, негативы —
без изменения состава экрана из f4.

## Состав (правки в `web/src/pages/IncidentCard.tsx`)

- **Нет видео** (`video_available=false`): placeholder вместо плеера + «Запросить архив»; график телеметрии остаётся автономным и работает.
- **Пустой `telemetry[]`** → блок графика показывает «нет телеметрии» (не пустой холст, не падение).
- **Sync**: `onTimeUpdate` плеера обновляет `playheadOffset` графика; клик по графику → `seekTo` на обоих плеерах (ADAS+DMS синхронны).
- **loading**: скелет топбара/видео/графика; **error/404**: явное состояние + «Назад к ленте» (не белый экран).
- **a11y**: `<video>` с `aria-label` (ADAS/DMS) и управлением с клавиатуры; график — `role="img"` + текстовое summary события (ax, скорость); фокус-кольца на плеерах/кнопках; модалки/панели возвращают фокус.
- **Локали/таймзона**: `ts` — ISO-8601 **UTC** (контракт); время и окна offline (`offline_from/to`) выводить в таймзоне парка через `toLocaleString` (не «сырой» UTC); числа `tabular-nums`.
- **Роли**: деструктивные действия «Стоп ТС»/«Валидация» — только Безопаснику; Логисту/Диспетчеру скрыты/disabled с подсказкой.
- **Негативы**: пустой `cam_extra[]` → секция «Другие камеры» скрыта; камера `warning` → бейдж «Нестабильна», плеер не блокируется; повторный `postAction` идемпотентен (кнопка disabled на время запроса, ошибка → тост + откат состояния).

## Check

- `/incidents/:id` рендерит карточку на живом API (после `make db`+бэк) и на фикстурах; `npm run typecheck` зелёный.
- Кейс «нет видео» → placeholder + «Запросить архив», график автономен; пустой `telemetry[]` → «нет телеметрии».
- Sync доказан: `onTimeUpdate` двигает `playheadOffset`; клик по графику → `seekTo` (оба плеера).
- loading/error/404 показывают явные состояния; деструктивные действия видны только Безопаснику.
- a11y: видео/график доступны с клавиатуры и скринридера; даты — в таймзоне парка, не «сырой» UTC.
- Действия пишутся (`POST /api/actions`), статус инцидента обновляется; повтор идемпотентен в UI.
- Регрессий по t3 (`IncidentCard`) нет.
