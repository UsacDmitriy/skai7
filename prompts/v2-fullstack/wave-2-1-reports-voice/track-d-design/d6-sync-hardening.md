## Цель

Сделать синк видео↔график **надёжным и «дорогим»** на уже построенных примитивах: без дёрганья,
утечек слушателей и обратных петель — **без изменения публичного API пропсов d2**
(`onTimeUpdate`/`seekTo`/`playheadOffset`/`eventMarkerPct`).

## Состав (правки в `VideoPlayer.tsx` и `TelemetryChart.tsx`)

- **`onTimeUpdate` троттлинг:** через `requestAnimationFrame`/throttle (~60–100 мс), не на каждый тик
  `timeupdate` — иначе ререндер графика «захлёбывается».
- **Контролируемый `seekTo` без петли:** применять `seekTo` к `video.currentTime` только при реальном
  расхождении (порог), не зацикливать `seek → timeupdate → seek`.
- **`playheadOffset` интерполяция:** движущаяся вертикаль графика плавная между точками `ts_offset`
  (без скачков на разреженной телеметрии); статичный маркер события (x=0) — отдельно, не путать.
- **Cleanup:** все слушатели (`timeupdate`/`loadedmetadata`) снимаются на `unmount`; `rAF` отменяется.
- **Пустые/битые состояния:** пустой `src` → «Видео недоступно» (без битого `<video>`);
  пустой `data[]` → график «нет телеметрии» (не пустой холст, не краш).
- **a11y:** `<video>` — `aria-label` (ADAS/DMS) и управление с клавиатуры; график — `role="img"`
  + текстовое summary (скорость/`ax`); видимые focus-кольца.
- **Без `Date.now()`** в логике синка — время берётся из `video.currentTime`/пропсов (детерминизм демо).

## Check

- Воспроизведение: `onTimeUpdate` двигает `playheadOffset` плавно; FPS графика не «захлёбывается» (троттлинг).
- Клик по графику → `seekTo` на плеере **без** обратной петли (нет дрожания/рекурсии).
- Размонтирование компонента не оставляет активных слушателей/`rAF` (нет варнингов React, нет утечек).
- Пустой `src` → «Видео недоступно»; пустой `data[]` → «нет телеметрии»; оба без краша.
- a11y: плеер и график доступны с клавиатуры и скринридера; публичный API пропсов d2 не изменён.
- `tsc --noEmit` зелёный; регрессий по t3 (`VideoPlayer`/`TelemetryChart`) и f14-синку нет.
