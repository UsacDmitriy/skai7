# Claude Design промпты — SKAI

Один набор: **по одному промпту на экран**, статус — прямо в имени файла.

- `--готов` — макет уже есть в `ui/`, генерировать заново не нужно (правки — только при изменении контракта).
- `--переработать` — макет есть, но требует переделки.
- `--новый` — макет ещё не сделан, нужно сгенерировать.

## Дизайн-система
`00-design-system.md` — спецификация токенов (severity, цвета, шрифты). **У тебя она уже загружена
в Claude Design — повторно вставлять не нужно.** Файл оставлен как справка/источник истины (синхронен
с `prompts/v2-fullstack/00-CONTRACT.md` §4/§7.6).

## Как использовать
1. Дизайн-система уже в твоём Claude Design (см. выше) — пропускаешь `00`.
2. Бери экран по статусу: сначала `--переработать` (`02`), затем `--новый` (`06–11`, `01`). `--готов` — не трогаешь.
3. Один файл = один запуск. Результат (standalone HTML + screenshot) → в соответствующую папку `ui/` (см. колонку `→ ui/`).

> Истина по данным/полям — `prompts/v2-fullstack/00-CONTRACT.md`. Макеты — визуальный референс.
