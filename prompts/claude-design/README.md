# Claude Design промпты — SKAI Unified Incident Window

Гибридный набор дизайн-промптов для будущего UI SKAI. Две группы файлов:

- **Канон — нумерованные `00`–`11`** (источник истины структуры и данных экранов).
- **`CD-P1`–`CD-P8` — готовые промпты** для вставки в claude.ai/design: каждый встраивает
  соответствующую нумерованную спеку + хвостовой блок «## Промпт для Claude Design».
  Хвостовой блок приведён в строгое соответствие встроенной спеке (тема/layout/severity/данные).

**Дизайн-система и данные:** `00-design-system.md` (severity по API critical/high/medium/low,
токены §7.6) и контракт `prompts/v2-fullstack/00-CONTRACT.md` (§4 токены, §7.5 схемы отчётов/Trip/Reb).

## Как использовать

Каждый файл (нумерованный или CD-P) = один запуск Claude Design.
Перед запуском загрузить System Prompt из `00-design-system.md`.
Порядок приоритета: сначала `03-idea1-*` и `05-idea2-*`, затем остальные.
Для готового текста-промпта брать хвостовой блок CD-P* (он не противоречит канон-спеке выше).
