## Дизайн-спека
# Экран 9 — Восстановление маршрута при РЭБ

## Из брифа организаторов
«Снижение влияния РЭБ за счёт анализа видео (проверка скорости, восстановление маршрута).»

РЭБ (радиоэлектронная борьба) — глушилки GPS. Телематика теряет трек.
Видео остаётся. Система восстанавливает маршрут по видеопотоку (дорожные признаки — НЕ CAN-шина).

## Что рисуем
Сравнение двух треков: GPS (с пропусками) и восстановленный по видео.

**Данные (канон-кейс inc-004):** маршрут Н124УУ 199 · Козлов И.А., участок 12:10–12:35 (25 мин).

## Layout 1440×900

**Header:** «Восстановление маршрута · Н124УУ 199 · Козлов И.А.»
Badge amber: «⚠️ GPS-сигнал потерян на 25 мин (12:10–12:35)»

**Две карты рядом:**

Левая «GPS-трек»:
- Синяя линия с пропуском 12:10–12:35 (пунктир серый «нет данных»)
- Badge красный: «Пропуск 25 мин · Возможно РЭБ»

Правая «Восстановлено по видео»:
- Та же линия, но участок 12:10–12:35 восстановлен оранжевым
- Точки распознанных ориентиров: знаки, перекрёстки, разметка
- Badge зелёный: «Маршрут восстановлен · Достоверность 87%»

**Под картами — панель доказательств (горизонтальный скролл):**
Кадры из видео с подписями: «Знак 60 км/ч», «Поворот направо», «Светофор ул. Ленина».
Клик на кадр → видеоплеер этого момента.

**Итоговая строка:**
«Средняя скорость на восстановленном участке: 74 км/ч (лимит 60 км/ч)»
Badge red: «Нарушение подтверждено видео»

Visual: Inter · bg #F8FAFC · primary #1E3A8A · язык: русский.
Output: React + Tailwind, один файл.
