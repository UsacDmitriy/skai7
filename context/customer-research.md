## Три ключевых клиента

### Фомин (PepsiCo, ~200 ТС, диспетчер безопасности)

**Контекст:** Использует телематику (CEIBA) + видеоаналитику (отдельная система).

**Главная боль:** «39 ДТП зафиксировано телематикой — видеоаналитика подтвердила не больше 5.
Если бы при смещении автомобиля автоматически подтягивалось видео — не нужно было бы прыгать между системами.»

**Что хочет:**
- CAN-скорость (не GPS) + видео ±30 сек в одном окне
- Единый отчёт для страховой с видео + телеметрией
- Понять причину события ДО звонка водителю

**Дал идею:** Блок причины события — [😴 Усталость] [📱 Телефон] [🚗 Подрезали] [⚙ Техн. сбой]

---

### Маслов (Балтика, ~300 ТС, 3 пилотных объекта)

**Контекст:** Пилотирует видеоаналитику, параллельно работает CEIBA.

**Главная боль:** «3 машины показываются как 5 точек из-за задвоения терминалов (телематика + видео).»

**Что хочет:**
- Статус каждой камеры (работает/нет) — видно сразу
- Кнопка звонка водителю через бортовую камеру
- Ролевое разграничение: логист видит маршруты, безопасник видит нарушения
- Простота: «один экран — всё что нужно диспетчеру»

**Дал идею:** [📹 Позвонить через камеру] — видеозвонок через DMS-камеру прямо из интерфейса.

---

### Оздоев (Газпромнефть, ~800 ТС, 5 стран)

**Контекст:** Строит внутреннюю платформу SMAP LPS 2.0. SKAI — именно то направление.

**Главная боль:** «Нажал нарушение в отчёте — должно сразу вылезти видео. Как на Sky Studio: нажал превышение скорости, вылез трек. А тут нажал нарушение — вылезет видео.»

**Что хочет:**
- Клик на строку нарушения → видео рядом (killer feature)
- Расширенный отчёт БВ с детекциями ВА: ремень, саботаж, курение, Drowsiness
- Автозапрос видео ±15 сек при резком торможении
- Масштаб: 800 ТС, несколько стран, разные роли

**Дал идею:** Интерактивный отчёт — NL-запрос → подтверждение → дашборд → клик → видео.

## Сводка болей (из CJM, 84 инсайта)

**Топ-5 болей:**
1. Переключение между системами CEIBA и ВА замедляет расследование
2. Камеры «грузятся но не работают» — нет единого статуса
3. Дублирование точек на карте (разные терминалы для одной машины)
4. Отчёты из двух систем не совпадают — сложно сопоставить вручную
5. Нет единого дашборда водителей с обоими источниками данных

**Топ-5 желаемых фич:**
1. Единая карточка события: трек + видео + телеметрия
2. Клик на нарушение → автоматическое видео
3. Ролевой доступ (логист/диспетчер/безопасник)
4. Видеозвонок водителю через камеру
5. Автоматический запрос видео при тревоге

## Acceptance criteria от клиентов

**Фомин (PepsiCo) скажет «куплю» если:**
- [ ] При открытии инцидента видео и телеметрия уже рядом
- [ ] CAN-скорость видна в графике (не только GPS)
- [ ] Блок причины события есть и сохраняется

**Маслов (Балтика) скажет «куплю» если:**
- [ ] Статус камер виден сразу (зелёный/красный)
- [ ] Кнопка звонка через камеру работает
- [ ] Один экран мониторинга для диспетчера, другой для логиста

**Оздоев (ГПН) скажет «куплю» если:**
- [ ] Клик на нарушение в отчёте → видео появляется рядом
- [ ] Отчёт объединяет ВА и телематику
- [ ] Работает на 800+ ТС (нет per-vehicle лимита)
