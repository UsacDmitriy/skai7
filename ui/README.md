# UI — макеты Claude Design (референсы для фронта)

Сюда кладём результаты Claude Design. Один экран = одна папка с `*.html` (standalone, inline Tailwind CDN)
+ `screenshot.png`. Фронт-трек (`prompts/v2-fullstack/track-f-frontend/*`) использует их как визуальный референс.

## Конвенция файлов в папке
- `<Экран>.html` — standalone (как `Карточка инцидента/SKAI Incident Card.html`).
- `screenshot.png` — превью итога.
- (опц.) `source.html` / варианты — рядом.

## Порядок генерации в Claude Design (web)
1. System prompt = `prompts/claude-design/00-design-system.md` (вставить один раз в начале сессии).
2. Приоритет: **перегенерить монитор** (`02`/`CD-P1`, карта-герой) → новые P1/P2: `06–11`, `CD-P5–P8`.
   Card/Report уже готовы — править только при изменениях контракта.
3. Сохранить standalone HTML в нужную папку выше + скриншот.

> Эти макеты — визуальный референс; «истина» по данным/полям — всегда `prompts/v2-fullstack/00-CONTRACT.md`.
