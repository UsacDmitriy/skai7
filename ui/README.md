# UI — макеты Claude Design (референсы для фронта)

Папки пронумерованы по дизайн-промптам `prompts/claude-design/`. Один экран = одна папка:
`<NN Экран>/<Экран>.html` (standalone, inline Tailwind CDN) + `screenshot.png`.
Фронт-трек (`prompts/v2-fullstack/track-f-frontend/*`) использует их как визуальный референс.

## Конвенция файлов
- `<Экран>.html` — standalone (как `03 Карточка инцидента/SKAI Incident Card.html`).
- `screenshot.png` — превью итога.

## Порядок генерации в Claude Design (web)
1. System prompt = `prompts/claude-design/00-design-system.md` (один раз в начале сессии).
2. Приоритет: **`02` перегенерить** (карта-герой) → новые `06–11` (`CD-P5–P8` + `10`,`11`) → `01`.
   `03`/`05` уже готовы — править только при изменениях контракта.
3. Сохранить standalone HTML + скриншот в соответствующую номерную папку.

> Истина по данным/полям — `prompts/v2-fullstack/00-CONTRACT.md`. Макеты — только визуальный референс.
